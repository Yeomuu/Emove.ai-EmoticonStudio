# EMOVE 1차 UI/로직 QA

## 범위

- API 연결과 유료 생성 결과는 제외
- `/home`, `/character`, `/input`, `/edit`, `/library`, `/showcase`
- 1920x1080 데스크톱, 1280x720 낮은 화면, 390x844 모바일
- 라이트/다크 모드, 경로 이동, 단계 이동, 캐러셀, 모달, 포인터 입력

## 통과 항목

- 홈 하단 도크의 모든 버튼 중심점이 실제 클릭 대상 위에 있고, 로고로 `/home` 이동 가능
- 작업 화면 도크는 우측 하단 포인터 진입 시 표시되고 링크/버튼을 클릭 가능
- 홈 캐릭터가 포인터의 불투명 픽셀 접촉에 반응하며 위치가 실제로 변함
- 캐릭터 Step 1→2→3 휠 이동과 드롭다운 레이어 클릭 가능
- 입력 화면은 촬영을 시작하지 않은 상태에서 다음 단계로 우회하지 못함
- 입력 경고 모달이 오버레이 최상단에서 읽히고 조작 가능
- 보관함 다음 버튼이 활성 카드와 가로 레일 위치를 함께 변경
- 보관함의 비활성 카드 작업 레이어가 카드 경계를 벗어나지 않음
- 쇼케이스의 포인터 반응 캔버스가 뷰포트 전체 크기로 렌더됨
- 390x844에서 페이지 자체의 가로 스크롤 없이 홈/캐릭터/입력/보관함 사용 가능
- 720px보다 낮은 작업 화면은 760px 최소 작업 높이를 유지하고 세로 스크롤로 전체 조작에 접근 가능
- 라이트/다크 모드에서 배경, 텍스트, 카메라 패널, 도크 색상 전환 확인

## QA 중 수정한 결함

- 캐릭터 Step 3 이미지 선택 칩이 설명문과 겹치던 절대 위치 기준 수정
- 촬영 전 하단 `다음 단계`로 정적 REC 화면에 진입하던 단계 검증 수정
- 편집 레이어 이름이 한 글자씩 세로로 쌓이던 좁은 그리드를 2행 조작 구조로 수정
- 캐릭터 생성 모바일 화면이 데스크톱 좌표를 축소해 읽을 수 없던 문제를 내부 세로 흐름으로 전환
- 모바일 홈 저작권 문구와 하단 도크의 겹침 방지

## 자동 검증

- `pnpm typecheck`: 통과
- `pnpm test`: 1개 파일, 11개 테스트 통과
- `pnpm build`: Next.js 프로덕션 빌드 통과
- `git diff --check`: 공백 오류 없음

## 참고

- 화면 좌측 하단의 검은 `N` 버튼은 Next.js 개발 서버 도구이며 프로덕션 빌드에는 표시되지 않음
- API 키, OpenAI 생성 품질, Imentiv 응답, Neon/GCS 원격 저장은 이번 1차 QA 판정에서 제외
- 각 PNG는 수정 전후를 포함한 현재 실행의 실제 브라우저 캡처
